# Python Email Simulator & User Configuration

Un projet de simulation de messagerie en **Programmation Orientée Objet (POO)** développé en Python, intégrant la gestion des utilisateurs, des boîtes de réception, des horodatages (timestamps) et des configurations de profils.

## 🚀 Fonctionnalités
- **Classes orientées objet** (`User`, `Inbox`, `Email`).
- **Gestion des horodatages** avec le module `datetime`.
- **Interface de simulation** permettant d'envoyer, lire, lister et supprimer des e-mails.
- **Gestion des configurations utilisateur** pour structurer les données et les états.

## 🛠️ Comment l'exécuter ?
Assure-toi d'avoir Python installé sur ta machine, puis lance le script directement depuis ton terminal :

```bash
python userConfiguration.py
